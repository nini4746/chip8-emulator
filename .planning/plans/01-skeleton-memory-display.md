# Plan 01: 골격, 메모리, ROM 로더, 첫 화면 출력

## 이 plan의 목표

빈 프로젝트에서 "IBM 로고가 창에 뜨는" 최소 에뮬레이터까지. SPEC의 R1 전체와 R3 일부 (로고 표시, 00E0) 를 구현한다.

## 시작 전에 알아야 할 컨텍스트

- 프로젝트: /Users/yunho/project/chip8-emulator (현재 README.md만 존재)
- SDL2: `brew install sdl2` 후 pkg-config로 플래그 획득 (`pkg-config --cflags --libs sdl2`)
- 테스트 롬: https://github.com/Timendus/chip8-test-suite 의 bin/ 에서 다운로드. roms/ 디렉토리에 보관
- CHIP-8 메모리맵: 0x000~0x1FF 인터프리터 영역 (폰트셋은 관례상 0x050~0x09F), 0x200부터 롬. 옵코드는 2바이트 빅엔디안
- IBM 로고 롬은 딱 6종 옵코드만 사용한다: 00E0, 1NNN, 6XNN, 7XNN, ANNN, DXYN. 그래서 이 plan의 마일스톤으로 정확히 맞는다

## 해야 할 작업

1. 디렉토리 구조와 Makefile. 소스 분리는 자유지만 최소한 "CPU 상태 + 옵코드"와 "SDL 입출력"은 파일을 나눠라 (부정 기준: 옵코드가 SDL을 직접 호출하면 안 됨)
2. CHIP-8 상태 구조체 정의: 메모리 4KB, V0~VF, I, PC, SP, 스택 16레벨, delay/sound 타이머, 64x32 프레임버퍼, 키패드 상태 16개
3. 초기화: 폰트셋 16글자를 0x050~0x09F에 적재, PC=0x200
4. ROM 로더: 파일 열기 실패, 3584바이트 초과 시 에러 메시지 + 종료. 인자 없으면 usage
5. SDL2 창 + 렌더링: 프레임버퍼를 정수배 스케일 (예: 10배 = 640x320) 로 그리기. ESC와 창 닫기로 종료
6. fetch-decode 디스패치 골격: 옵코드 상위 니블로 분기하는 구조를 잡고, 위 6종 옵코드만 구현. 나머지는 "미지 옵코드: PC와 옵코드 출력 후 정지" 경로로
7. 테스트 롬 다운로드해서 roms/에 배치

## 빠지면 실패인 것

- 렌더링이 프레임버퍼만 읽는 구조 (옵코드 → 프레임버퍼 → 렌더러의 단방향)
- DXYN의 XOR 그리기와 VF 충돌 플래그 (로고 롬은 충돌이 없지만 지금 넣어야 plan 02가 편하다)
- 미지 옵코드 정지 경로 (이게 있어야 이후 plan에서 뭘 빠뜨렸는지 바로 보인다)

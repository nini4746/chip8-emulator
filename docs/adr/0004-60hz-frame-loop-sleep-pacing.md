# 0004. 60Hz 프레임 루프와 sleep 기반 페이싱

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
CPU는 700 IPS, delay/sound 타이머는 60Hz로 돌아야 하며 두 속도는 서로 독립이어야 한다. 메인 루프가 sleep 없이 CPU를 태우면 안 된다는 것도 부정 수용 기준이다.

## 결정
- `main.c`의 `CHIP8_CPU_HZ`(700)와 `CHIP8_TIMER_HZ`(60)를 독립 상수로 둔다.
- 프레임마다 최대 `CHIP8_CPU_HZ / CHIP8_TIMER_HZ`(11)개 명령을 실행하고, `chip8_tick_timers`로 타이머를 1회 감소한다.
- `platform_delay_ms`로 남은 시간만큼 sleep한다. 처리가 주기보다 늦으면 밀린 프레임을 몰아서 처리하지 않고 기준 시각을 현재로 재설정한다.
- vsync는 끈다.

## 대안
- 명령 수에 묶인 타이머: IPS를 바꾸면 타이머 속도도 바뀐다.
- 별도 스레드 타이머: 두 속도를 독립 상수로 두는 데 필요하지 않다.
- busy-spin: CPU 한 코어를 다 쓴다.
- vsync: 타이머 속도가 화면 주사율에 묶인다.

## 결과
- 장점: IPS 상수를 바꿔도 타이머 속도가 변하지 않는다. 유휴 시 CPU를 태우지 않는다.
- 단점/감수한 점: CPU 속도는 프레임 단위로만 조절되며 프레임당 명령 수는 정수(11)로 내림된다.

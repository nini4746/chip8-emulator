# 0005. 메모리 주소를 0x0FFF로 마스킹

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
롬이 I나 PC를 4KB 범위 밖으로 보낼 수 있다. 이때 에뮬레이터 프로세스 메모리를 침범하면 안 된다는 것이 부정 수용 기준이다. SPEC은 마스킹과 에러 정지 중 하나를 허용했다.

## 결정
모든 메모리 인덱스를 `chip8.c`의 `mem_addr()`로 `addr & 0x0FFF` 마스킹한다. I나 PC가 0xFFF를 넘으면 4KB 안에서 감싸서 접근한다. 스택 오버플로/언더플로와 미지 옵코드는 따로 정지 처리한다.

## 대안
- 범위 이탈 시 에러 정지: 채택하지 않았다. 마스킹으로도 프로세스 메모리는 보호된다.

## 결과
- 장점: 어떤 I/PC 값이 와도 배열 밖을 읽거나 쓰지 않는다.
- 단점/감수한 점: 범위를 벗어난 접근이 오류로 드러나지 않고 감싸진 주소로 조용히 처리된다.

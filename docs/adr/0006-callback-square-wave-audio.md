# 0006. 콜백 방식 440Hz 사각파 비프, 오디오 실패 시 무음으로 계속

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
sound 타이머가 0보다 큰 동안 가청 비프음이 나야 한다. 파형 품질과 볼륨 옵션은 범위 밖이고 가청 여부만이 목표다.

## 결정
- `platform.c`의 `audio_callback`이 440Hz 사각파(진폭 6000, 44100Hz, S16 mono, 버퍼 512샘플)를 만든다.
- 메인 루프는 `platform_set_beep(sound_timer > 0)`로 `volatile int beep_on`만 바꾼다. 오디오 스레드와 공유하는 값은 이것 하나다.
- 오디오 장치 열기에 실패하면 `warning: audio unavailable`을 출력하고 무음으로 계속 실행한다.

## 대안
- `SDL_QueueAudio`: 채택하지 않았다. 파형 품질은 범위 밖이다.
- 오디오 실패 시 종료: 소리가 없어도 에뮬레이션은 의미가 있다.

## 결과
- 장점: 공유 상태가 플래그 하나라 스레드 처리가 단순하다. 오디오 장치가 없어도 실행된다.
- 단점/감수한 점: 톤과 볼륨을 바꿀 수 없다.
